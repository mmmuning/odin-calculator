## Calculator

This project is part of **The Odin Project’s Foundations Course**. It’s an interactive on-screen calculator built with **HTML, CSS, and JavaScript**, designed to apply everything I’ve learned from DOM manipulation and event handling lessons.

### This project includes:

* A clean, responsive calculator layout styled with CSS
* Full functionality for basic operations: addition, subtraction, multiplication, and division
* Support for chained calculations and decimal inputs
* Equation and result displays that update dynamically
* Keyboard input support for numbers, decimals, and backspace

### Through this project, I practiced and demonstrated:

* Building interactive interfaces with JavaScript
* Handling user input through both button clicks and keyboard events
* Updating the DOM dynamically based on program state
* Writing modular, readable functions for cleaner logic flow
* Managing UI state between multiple display areas
* Designing a simple, accessible layout with consistent styling
